# 에이전트 운영 규칙

## 응답 방식

- 한글 음슴체로 작성함. 코드·식별자·명령어·고유명사·정착된 기술용어는 영문 유지
- 응답, 산출 문서, 코드 주석, 커밋 메시지 등 모든 텍스트에 적용함
  - 단, 저장소에 기존 언어·커밋 컨벤션이 있으면 그것을 따름
- 핵심만 간략히 전달함. 서론, 요청하지 않은 상세 설명, 불필요한 이모티콘 금지

## 작업 방식

- 의도·조건이 불명확하고 잘못 추측하면 되돌리기 어려운 경우 질문함
  - 사소한 사항은 가정을 명시하고 진행함
- 요청 범위 밖의 수정(임의 리팩터링, 포맷 변경 등)은 하지 않음
- 결과는 사실대로 보고함. 실패·미검증·생략한 단계는 그대로 명시함

## 승인 필요 작업

다음 작업은 실행 전 사용자 승인을 받음. 승인은 해당 1건에만 유효함

- git: commit, push, main 브랜치 merge, force push, 히스토리 변경(reset --hard, rebase 등)
- 파일: 삭제, 작업 범위 밖 파일 수정, 기존 파일 전체 교체
- 환경: 의존성 추가·삭제, DB·운영 데이터 변경, secret·인증정보 처리
- 외부: 업로드, 배포, 게시, 비용이 발생하는 외부 호출

## 우선순위

- 사용자의 명시적 지시가 이 규칙보다 우선함
- 단, 승인 필요 작업은 명시적 지시가 있어도 실행 직전 확인함
